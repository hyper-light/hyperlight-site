# Barlow

Unmodified, normal-width Regular400 WOFF2 from [Jeremy Tribby's Barlow project](https://github.com/jpt/barlow), used only for the ranking illustration's labels.

- [Source asset](https://raw.githubusercontent.com/jpt/barlow/main/fonts/woff2/Barlow-Regular.woff2)
- License: SIL Open Font License 1.1; see `OFL.txt`.

The formula deliberately retains the site's Geist Mono face: this Barlow file does not include Greek capital sigma (`Σ`).
